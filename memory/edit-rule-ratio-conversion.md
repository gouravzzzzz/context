name: edit-rule-ratio-conversion
description: "Converting a reel/storyboard between vertical and horizontal: only the aspect ratio changes; graphics centred; text left/centre/right aligned by side"
metadata:
  type: feedback
---

When the user asks to convert a storyboard or reel from vertical (1080x1920) to horizontal (1920x1080), or the other way, change **only the ratio**. Keep the same shots, captions, words, boxed key words, typing states, grade, fonts, colours and elements.
- Every graphic (boxes, cards, articles, logos, match-cut faces) sits **centred** in the new frame.
- Text stays **left-, centre- or right-aligned** to the side it sits on, never in between ([[edit-rule-text-alignment-by-side]]).
- Talking-head raw is full-frame and centred ([[edit-rule-talking-head-framing]]).

**Why:** On 2026-11-20, for the Kristina Shea trailer, the user said: "convert the storyboard to horizontal everything should be center, left or right aligned remember this and every graphics should be centered nothing should change except the ratio".

**How to apply:**
- Re-lay each still for the new frame from the same sources, keeping the face/subject positions and the caption-to-subject relations.
- Write the stills to a separate folder, keeping the other version.
- Compare each new still against its vertical twin before delivering.
